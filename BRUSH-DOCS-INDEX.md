## 🎨 Feature Quick Reference

### Core Parameters
- **Size** (1-200px) - Brush diameter
- **Opacity** (1-100%) - Transparency
- **Hardness** (0-100%) - Edge softness
- **Flow** (1-100%) - Build-up control ⭐
- **Spacing** (1-100%) - Dab distance ⭐

### Dynamics
- **Smoothing** (0-100) - Stabilization ⭐
- **Angle** (0-360°) - Rotation ⭐
- **Angle Jitter** (0-180°) - Random rotation ⭐
- **Scatter X** (0-100%) - Horizontal displacement ⭐
- **Scatter Y** (0-100%) - Vertical displacement ⭐

### Presets
1. **Basic** - General purpose
2. **Soft** - Blended strokes
3. **Airbrush** - Spray effect
4. **Charcoal** - Textured drawing
5. **Ink** - Clean lines
6. **Watercolor** - Transparent washes

⭐ = New feature
