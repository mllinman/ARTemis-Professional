## ⚡ Advanced Brush Dynamics

### Velocity-Based Dynamics
**Inspired by: Krita Brush Engine**

Real-time stroke velocity affects brush behavior:

- **Velocity → Size (0-100%)**: Faster strokes create larger marks
- **Velocity → Opacity (0-100%)**: Speed affects transparency
- **Exponential Smoothing**: Natural velocity tracking without jitter

**How to Use:**
1. Select any brush
2. Open "Brush Dynamics" section
3. Adjust "Velocity → Size" slider
4. Draw fast = bigger strokes, slow = smaller strokes

**Professional Tip:** Use 40-60% velocity-to-size for natural calligraphy effects

---

### Tilt Sensitivity Support
**Inspired by: Photoshop, Krita**

Full pen display support for professional stylus users:

- **Tilt → Size (0-100%)**: Pen angle affects brush size
- **Tilt → Angle (0-100%)**: Natural brush rotation from tilt
- **Tilt → Opacity (0-100%)**: Tilt affects transparency
- **Full tiltX/tiltY/twist tracking**: Complete stylus data capture

**Supported Devices:**
- Wacom Cintiq/Intuos Pro
- Huion Kamvas
- XP-Pen Artist
- Surface Pen
- Apple Pencil (on compatible devices)

**How to Use:**
1. Connect your pen display/tablet
2. Open "Brush Dynamics" section  
3. Adjust tilt sliders to preference
4. Tilt your pen while drawing to see effects

**Professional Tip:** Use 30-50% tilt-to-angle for realistic calligraphy brushes

## 🎭 Photoshop-Style Advanced Blend Modes

### New Color Blend Modes (4 Added)
**Inspired by: Adobe Photoshop**

Professional HSL-based color blending:

1. **Hue Blend Mode**
   - Applies source layer's hue to target
   - Preserves target saturation and brightness
   - Perfect for: Color correction, mood changes

2. **Saturation Blend Mode**
   - Applies source layer's saturation to target
   - Preserves target hue and brightness
   - Perfect for: Enhancing/reducing color intensity

3. **Color Blend Mode**
   - Applies source hue + saturation to target
   - Preserves target brightness
   - Perfect for: Colorizing grayscale, recoloring artwork

4. **Luminosity Blend Mode**
   - Applies source brightness to target
   - Preserves target hue and saturation
   - Perfect for: Shading without color shift, tonal adjustments

**How to Use:**
1. Create two or more layers
2. Paint or import artwork
3. Select layer blend mode from dropdown
4. Choose Hue, Saturation, Color, or Luminosity
5. Adjust layer opacity for subtlety

**Professional Techniques:**
- **Dodge & Burn**: Use Luminosity mode with white/black layers
- **Color Grading**: Use Color mode to apply color overlays
- **Desaturation**: Use Saturation mode with gray layer
- **Tinting**: Use Hue mode to shift entire color palette

## 💡 Professional Workflows

### Digital Oil Painting
1. Select "Oil Paint" or "ArtRage Thick Oil" brush
2. Enable "Mixer Wet" for color blending
3. Use "Impasto Thick" for texture highlights
4. Apply "Metallic Gold" for shimmer accents
5. Use "Overlay" or "Color" blend modes for glazing

### Comic Book Inking
1. Start with "Nib Pen Medium" or "Ink Fine"
2. Enable high smoothing (30-40) for clean lines
3. Use velocity dynamics for variable line weight
4. Add texture with "Stipple" brush
5. Use "Multiply" blend mode for shadows

### Portrait Painting
1. Block in shapes with "Digital Hard" brush
2. Blend with "Blender Soft" brush
3. Add texture with "Texture Canvas"
4. Use "Dodge" and "Burn" tools with Luminosity mode
5. Add metallic jewelry with "Metallic Gold/Silver"

### Abstract Texture Art
1. Layer multiple "Texture" brushes
2. Use "Sponge Natural" for organic patterns
3. Apply "Metallic" and "Pearlescent" accents
4. Experiment with "Color" and "Hue" blend modes
5. Add finishing touches with "Special Effects" brushes
