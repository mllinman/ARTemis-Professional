# Photo Editing Tools - Quick Reference Card

## 🎨 New Photo Editing Tools

### Crop Tool (C)
```
🔹 Click and drag to select crop area
🔹 Dark overlay shows what will be removed
🔹 Release to apply crop
🔹 All layers are cropped together
```

### Clone Stamp (K)
```
🔹 Alt+Click to set source point
🔹 Click and drag to paint cloned pixels
🔹 Respects brush size and opacity
🔹 Perfect for removing objects
```

### Dodge Tool (O)
```
🔹 Click and drag to lighten areas
🔹 Multiple passes increase effect
🔹 Pressure-sensitive intensity
🔹 Great for highlights and eyes
```

### Burn Tool (U)
```
🔹 Click and drag to darken areas
🔹 Multiple passes increase effect
🔹 Pressure-sensitive intensity
🔹 Perfect for shadows and depth
```

### Sponge Tool (P)
```
🔹 Click and drag to adjust saturation
🔹 Default mode: Saturate (increase color)
🔹 Pressure-sensitive intensity
🔹 Great for color correction
```

### Flip Tools
```
🔹 Image → Flip Horizontal (left-right)
🔹 Image → Flip Vertical (top-bottom)
🔹 Works on active layer only
🔹 Great for creating symmetry
```

## 💡 Quick Tips

### Clone Stamp
✓ Set source near the target area  
✓ Use soft brush for seamless blending  
✓ Sample multiple source points for variety

### Dodge & Burn
✓ Use low exposure (10-30%) for subtle effects  
✓ Build up effect with multiple passes  
✓ Dodge for highlights, Burn for shadows

### Sponge
✓ Saturate to make colors pop  
✓ Desaturate for subtle color reduction  
✓ Great for selective color adjustments

### Crop
✓ Preview before applying  
✓ Cannot be undone after saving  
✓ Minimum size: 10x10 pixels

## 🎯 Common Workflows

### Photo Retouching
1. Clone Stamp (K) → Remove blemishes
2. Dodge (O) → Brighten eyes
3. Burn (U) → Deepen shadows
4. Sponge (P) → Enhance colors

### Creative Editing
1. Crop (C) → Frame composition
2. Flip → Create symmetry
3. Dodge/Burn → Add drama
4. Sponge → Color grading

### Object Removal
1. Clone Stamp (K) → Alt+Click nearby area
2. Paint over unwanted object
3. Vary source points for natural look
4. Adjust brush size as needed

## 🔧 Troubleshooting

### Clone Stamp not working?
→ Make sure you've set a source point with Alt+Click

### Dodge/Burn too strong?
→ Reduce brush opacity in the left panel  
→ Use lighter pressure with pen tablets

### Crop not appearing?
→ Make sure Crop tool (C) is selected  
→ Click and drag to create selection

### Effects not visible?
→ Check that active layer is selected  
→ Ensure layer opacity is 100%
