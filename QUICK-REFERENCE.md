## 🎯 Quick Usage

### Create a Gradient
```
1. Press L
2. Choose type (Linear/Radial)
3. Select colors
4. Click & drag on canvas
```

### Transform Layer
```
Move:   Press V → Drag
Rotate: Press R → Drag
Scale:  Press Z → Drag up/down
```

### Apply Filter
```
1. Select layer
2. Click filter button OR
   Use Filters menu
3. Enter parameters
4. Filter applies
```

### Save Custom Brush
```
1. Configure brush settings
2. Click "Save Preset"
3. Enter name
4. Saved!
```

### Use Blend Mode
```
1. Select layer
2. Choose blend mode
3. See instant result
```

### Create Adjustment Layer
```
1. Select "⚙️ Adjust" type
2. Click +
3. Affects layers below
```

## 💡 Pro Tips

### Gradients
- Hold Shift for straight lines
- Longer drag = smoother transition
- Use opacity slider for subtle effects

### Transforms
- Duplicate layer before transform
- Use Ctrl+Z to undo
- Combine multiple transforms

### Filters
- Try filters on duplicates first
- Stack filters for complex effects
- Use blur for soft focus

### Blend Modes
- Multiply for shadows
- Screen for highlights
- Overlay for contrast
- Experiment!

### Brushes
- Export brushes as backup
- Share JSON files with friends
- Load textures for stamps

### Plugins
- Study example code
- Test in console first
- Share useful plugins

## 🚀 Getting Started

1. **Try the Gradient Tool**
   - Press `L`
   - Drag to create
   - Experiment with types

2. **Transform Something**
   - Press `V`, `R`, or `Z`
   - Move, rotate, or scale
   - See changes live

3. **Apply a Filter**
   - Click a filter button
   - Enter values
   - Instant results

4. **Use Blend Modes**
   - Select a layer
   - Change blend mode
   - See magic happen

5. **Save Your Brush**
   - Configure settings
   - Click Save Preset
   - Reuse anytime
