## 🚀 No Installation Required!

**ARTemis is now completely self-sufficient** - just open `src/index.html` in any modern browser and start creating! No Node.js, no npm, no dependencies, no installation needed.

![ARTemis running in browser](https://github.com/user-attachments/assets/c4c4f191-da04-455f-833f-9d39a38e2bc9)

**Quick Start:**
1. Download or clone this repository
2. Open `src/login.html` in your browser (new users) or `src/index.html` (direct access)
3. Choose your authentication method (Google, Guest, or Admin)
4. Start painting immediately!

## Installation

### 🌐 Option 1: Standalone Browser (No Dependencies!)

**ARTemis now works directly in your browser without any installation!**

1. Clone or download this repository
2. Open `src/index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari)
3. Start creating immediately!

**Advantages:**
- ✅ Zero dependencies - no Node.js or npm needed
- ✅ No installation required
- ✅ Works on any device with a modern browser
- ✅ Fully self-sufficient
- ✅ All features work in browser mode

**Note:** File operations use the browser's File System Access API (Chrome/Edge) with automatic fallback to download/upload for other browsers.

### 💻 Option 2: Desktop App (Electron - Optional)

For a native desktop experience with OS-level file dialogs:

```bash
# Install dependencies (requires Node.js and npm)
npm install

# Run the application
npm start
```

**Desktop app advantages:**
- Native OS file dialogs
- Desktop application window
- OS menu integration

## Architecture

The application is built with a modular, self-sufficient architecture:

- `src/index.html` - UI structure and layout (works standalone in browser)
- `src/renderer.js` - Canvas rendering engine, tools, and interaction logic (includes browser compatibility layer)
- `src/styles.css` - Professional dark mode styling
- `src/main.js` - Optional Electron main process for desktop app mode

### State Management
The application maintains a centralized state object that tracks:
- Canvas dimensions and zoom
- Active tool and tool settings
- Layers and active layer
- Drawing state
- History for undo/redo

### Layer System
Each layer is implemented as a separate HTML5 canvas, providing:
- True non-destructive editing
- Independent layer visibility
- Efficient compositing
- Thumbnail generation

### Brush Engine
The advanced brush engine features:
- Pressure-sensitive size and opacity with custom curves
- 5 pressure curve types (linear, ease-in, ease-out, ease-in-out, custom)
- Configurable hardness for soft/hard edges
- Three different smoothing algorithms (Basic, Weighted, Stabilizer)
- Smooth stroke interpolation with prediction
- Color dynamics (hue, saturation, brightness jitter)
- Canvas color mixing (Painter-style pickup)
- Bristle dynamics (1-50 bristles with length & stiffness)
- Dual brush system with 4 blend modes
- Wet mixing and bleeding for watercolor effects
- Full Wacom, XP-Pen, Huion tablet support
- Pen rotation, tilt, and pressure support
- Adaptive quality for performance
- Efficient rendering with texture caching
- 178+ professional brush presets across 17 categories
