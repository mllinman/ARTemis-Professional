# Rebelle Graphite Brushes - Professional Drawing Tools

## Overview

ARTemis features a complete set of 8 professional-grade graphite pencil brushes inspired by Rebelle's realistic drawing tools. These brushes accurately simulate real graphite pencils from extra-soft 8B to extra-hard 4H, with authentic paper tooth response, tilt support, and grade-specific characteristics.

## Realistic Features

### Paper Tooth Response
All graphite brushes respond to paper texture and wetness:
- **Dry Paper (0% wetness)**: Maximum tooth visibility, grainy texture
- **Damp Paper (50% wetness)**: Moderate texture, some smoothing
- **Wet Paper (100% wetness)**: Reduced texture, smoother application

Enable the **Rebelle 8 Paper Panel** in Advanced Features to control paper wetness.

### Tilt Support
All brushes support pen tilt for natural drawing:
- **Vertical (0° tilt)**: Normal point size
- **Tilted (45-60°)**: Broader stroke for shading
- Softer grades respond more to tilt (8B: 80% vs 4H: 45%)
- Automatic angle adjustment follows tilt direction

### Grade-Specific Texture
Each grade has unique texture characteristics:
- **Soft (B) grades**: Higher grain intensity, particle-rich coverage
- **Medium (HB)**: Balanced grain pattern
- **Hard (H) grades**: Lower grain intensity, more paper tooth visible
- Directional streaking follows brush angle

### Layering and Build-up
- **B grades**: Build up faster to darker tones (1.2x multiplier)
- **HB**: Normal layering (1.0x)
- **H grades**: Build up slower, maintain lightness (0.7x multiplier)

## Usage Guide

### Basic Sketching
1. Start with **2B** or **HB** for initial sketch
2. Use **4B** or **6B** for shading
3. Add darks with **8B**
4. Refine details with **H** or **2H**

### Portrait Drawing
1. **2H** or **HB** for initial construction
2. **2B** or **4B** for general tones
3. **6B** or **8B** for hair and deep shadows
4. **H** for highlights and fine details

### Technical Drawing
1. **4H** or **2H** for construction lines
2. **HB** for main lines
3. **2B** for emphasis
4. Erase construction lines easily

### Tonal Studies
1. Use **8B** tilted for broad coverage
2. Layer **6B** and **4B** for mid-tones
3. **2B** and **HB** for light areas
4. Blend with smudge tool
5. Add highlights by erasing or using **H** grades

## Pro Tips

1. **Pressure Control**: Vary pressure for different tones with the same grade
2. **Layering**: Build up darks gradually with multiple light layers
3. **Hatching**: Use angled strokes with consistent angle for texture
4. **Cross-hatching**: Layer strokes at different angles
5. **Blending**: Use smudge tool between layers for smooth transitions
6. **Erasing**: Erase through layers to create highlights
7. **Tilt Technique**: Tilt pen for broad shading, vertical for details
8. **Grade Selection**: Use multiple grades in one drawing for variety
9. **Paper Settings**: Adjust wetness for different effects
10. **Speed**: Draw faster for lighter marks, slower for darker

## Troubleshooting

**Q: Brushes look too smooth, not grainy enough**
- A: Enable Rebelle 8 Paper Panel and set wetness to 0% (dry)
- Enable canvas texture overlay for additional grain

**Q: Tilt not working**
- A: Ensure your device supports tilt (Wacom, XP-Pen, Huion, iPad)
- Check that tilt settings are enabled in brush properties

**Q: Marks too dark/light**
- A: Adjust opacity slider or switch to different grade
- Use lighter pressure for softer marks

**Q: Can't blend smoothly**
- A: Use smudge tool with 30-50% strength
- Layer multiple light strokes instead of one heavy stroke

**Q: Lines look pixelated**
- A: Increase canvas resolution
- Use smoothing slider for cleaner lines
