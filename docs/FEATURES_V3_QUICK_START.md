## 🔍 Key Technology Explained (Simple Terms)

### WebGPU
**What it is:** Next-generation graphics API for web browsers  
**What it means:** Much faster rendering, smooth 240Hz displays, better effects  
**Why you care:** Your art tools work faster and smoother

### WebAssembly
**What it is:** Run high-performance code in web browsers  
**What it means:** ARTemis runs at near-native speed in your browser  
**Why you care:** No download needed, but still super fast

### Progressive Web App (PWA)
**What it is:** Website that works like a native app  
**What it means:** Install from browser, works offline, updates automatically  
**Why you care:** Use ARTemis on any device without app stores

### Tiled Rendering
**What it is:** Break large canvases into small tiles  
**What it means:** Work on 32K+ canvases without running out of memory  
**Why you care:** Create massive artwork without limits

### Neural Networks
**What it is:** AI that learns patterns and makes predictions  
**What it means:** Smart tools that understand your creative intent  
**Why you care:** AI helps you create better art faster

## 🚨 What's NOT in V3 (For Transparency)

### Out of Scope
- ❌ Desktop publishing (use InDesign/Affinity Publisher)
- ❌ Video editing (use Premiere/DaVinci Resolve)
- ❌ Audio editing (use Audacity/Audition)
- ❌ CAD/technical drawing (use AutoCAD/Fusion 360)
- ❌ 3D modeling (use Blender/Maya) - but we integrate with them!

### Requires Backend Infrastructure
- ⏳ Real-time collaboration (requires server)
- ⏳ Cloud rendering (requires GPU farms)
- ⏳ Marketplace (requires payment processing)
- ⏳ Social features (requires user accounts)

These are planned but need infrastructure investment.
