## Updating Screenshots

To update screenshots:
1. Make your UI changes
2. Start a local server: `python3 -m http.server 8080`
3. Open the page in a browser
4. Take screenshots at appropriate resolutions
5. Save to this directory with descriptive names
6. Update this README with new screenshot information

## Screenshot Standards

- **Format:** PNG with transparency where applicable
- **Resolution:** Full HD (1920x1080) or higher for general screenshots
- **Quality:** High quality, no compression artifacts
- **Naming:** Use kebab-case with descriptive names (e.g., `splash-page-screenshot.png`)
- **Content:** Show the feature or interface element clearly
- **Context:** Include enough surrounding UI for context
