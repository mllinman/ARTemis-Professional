# ARTemis Professional Assets

This directory contains icon assets for the Progressive Web App (PWA) functionality.

## Icon Sizes

- `icon-192.png` - 192x192px icon for PWA manifest (standard)
- `icon-512.png` - 512x512px icon for PWA manifest (high-res)

## Source Files

The icons are generated from SVG source files located in `/website/images/`:
- `icon-192.svg` - Source for 192px icon
- `icon-512.svg` - Source for 512px icon
- `logo-professional.svg` - Full professional logo with details

## Regenerating Icons

If you need to regenerate the PNG icons from SVG sources, you can use the provided generation script or any SVG to PNG converter.
