# Website Assets

## Required Images

Place the following images in this directory:

1. **logo.png** - BulletDrop Studios logo (recommended size: 200x200px or similar)
2. **favicon.png** - Website favicon (16x16, 32x32, or 64x64px)
3. **app-screenshot.png** - Screenshot of ARTemis application (recommended: 1200x800px or larger)

## Optional Images

Additional images can be added for:
- Feature demonstrations
- Tutorial screenshots
- Team photos
- Blog post images

## Image Guidelines

- Use PNG format for logos and icons (supports transparency)
- Use JPEG for photographs and screenshots (smaller file size)
- Optimize images for web (compress without losing quality)
- Use descriptive filenames
- Include alt text in HTML for accessibility
