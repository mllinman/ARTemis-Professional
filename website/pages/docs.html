Quick Start Guide

Getting Started with ARTemis

  1. Launch the App: Click "Launch App" or open src/login.html in your browser
  2. Choose Authentication: Sign in with Google, continue as Guest, or use Admin login
  3. Create New Canvas: File → New Canvas (Ctrl/Cmd + N)
  4. Select a Tool: Choose Brush (B), Eraser (E), or any other tool from the toolbar
  5. Start Creating: Draw on the canvas with your mouse, stylus, or touch input
  6. Save Your Work: File → Save Project (Ctrl/Cmd + S)

Keyboard Shortcuts

Tools

  • B - Brush
  • E - Eraser
  • G - Fill
  • I - Eyedropper
  • M - Selection
  • T - Text
  • S - Shapes
  • L - Gradient
  • [ / ] - Brush size

File Operations

  • Ctrl/Cmd + N - New canvas
  • Ctrl/Cmd + O - Open project
  • Ctrl/Cmd + S - Save project
  • Ctrl/Cmd + Shift + S - Save as
  • Ctrl/Cmd + E - Export image

Edit

  • Ctrl/Cmd + Z - Undo
  • Ctrl/Cmd + Shift + Z - Redo
  • Escape - Clear selection

View

  • Ctrl/Cmd + = - Zoom in
  • Ctrl/Cmd + - - Zoom out
  • Ctrl/Cmd + 0 - Fit to screen
  • Ctrl + Wheel - Zoom
  • Middle Mouse - Pan

Layers

  • Ctrl/Cmd + Shift + N - New layer
  • Ctrl/Cmd + J - Duplicate layer
  • Delete - Delete layer
  • Ctrl/Cmd + ] - Move layer up
  • Ctrl/Cmd + [ - Move layer down
